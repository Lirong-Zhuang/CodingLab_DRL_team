# Setup

## Python version

Python 3.11 is recommended. This project was tested with Python 3.11.6.

## Create virtual environment

python3 -m venv .venv

## Activate

Linux/macOS:

source .venv/bin/activate

Windows:

.\.venv\Scripts\Activate.ps1

## Install dependencies

pip install -r requirements.txt

## Run

python main.py
